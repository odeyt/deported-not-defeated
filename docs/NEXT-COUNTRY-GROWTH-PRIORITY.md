## Read this before using the ranking

The scoring below uses **content depth and provider coverage**, both measured.
It does **not** use search impressions, rankings, or traffic, because Search
Console is not connected.

That means the most important variable is absent. A country with deep content
and no search demand should not be next; a country with thin content and real
impressions probably should. **This ranking cannot tell you which is which.**

Use it to prepare, not to decide. Reorder it the week GSC data arrives.

## The pattern that matters more than the order

**Every country on this list has Mexico's bottleneck.** Money transfer is the
strongest commercial category everywhere, and one provider is monetized on the
one corridor that has been examined.

Replicating Mexico's architecture to Guatemala produces a second page where
seven of eight providers earn nothing. Expansion multiplies pages; it does not
multiply revenue while approvals stay where they are.

**The order of operations should be:**

1. Connect Search Console — find out which countries already get impressions
2. Convert approvals for the categories that get traffic
3. *Then* expand into countries the data supports

Not the reverse. The infrastructure to expand is finished and will still be
finished in three months.
